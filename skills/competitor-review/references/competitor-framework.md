# 竞品分析四维框架方法论

> 适用范围：电商零售品牌（美妆个护、食品饮料、消费电子、服饰、母婴、酒类等）的竞品结构化对比。
> 核心原则：先对齐口径，再对比；先给结论，再给证据；区分实查与推断。

## 维度一：价格带分析

### 口径对齐
- 到手价 = 页面价 − 平台券 − 店铺券 − 单品直降 + 赠品折算（赠品按成本价或零售价折算需注明）；
- 单位价格 = 到手价 / 净含量（ml、g、片、件），跨品牌对比必须用单位价格；
- 套装拆开算单品等效价（如"精华 30ml + 面霜 15g"套装，按主品容量折算）。

### 价格带分段
| 段位 | 定义方法 | 分析要点 |
|---|---|---|
| 高端段 | 品类单位价格 P75 以上 | 品牌溢价来源、礼赠场景占比 |
| 中端段 | P25–P75 | 主战场，卖点密度最高 |
| 低端段 | P25 以下 | 走量逻辑、渠道下沉 |

### 关键判断
1. 本品价格站位：在哪个段位、与最近竞品的价差百分比；
2. 价格锚点：竞品是否用高价 SKU 做锚（衬托主力款性价比）；
3. 促销价穿透：大促到手价是否击穿日常价体系（判断竞品价格纪律性）；
4. 渠道价差：天猫/京东/抖音/拼多多价格体系是否一致（不一致 = 窜货风险或渠道差异化策略）。

## 维度二：卖点拆解

### 卖点分层
| 层级 | 内容 | 示例（美妆） |
|---|---|---|
| 功能层 | 成分、技术、功效 | 玻色因 30%、专利包裹技术 |
| 体验层 | 质地、香型、包装、使用感 | 轻薄不黏腻、磁吸盖设计 |
| 情绪层 | 身份认同、价值观、场景 | 早 C 晚 A 护肤仪式感 |
| 服务层 | 售后、赠品、会员权益 | 过敏包退、小样试用 |

### 拆解步骤
1. 从竞品主图前 3 张 + 详情页首屏提取"主打卖点"（品牌方最想让你记住的）；
2. 从评价高频好评词提取"实际感知卖点"（消费者真正买账的）；
3. 两者差集 = 竞品"宣称但未兑现"的卖点 → 本品攻击点；
4. 识别同质化卖点（全行业都在说）vs 独占卖点（仅该竞品有），独占卖点评估可跟进性。

## 维度三：评价分析

### 快速口径（本技能内完成）
- 评分 × 销量组合：高评分高销量 = 真实威胁；高评分低销量 = 声量不足；低评分高销量 = 有弱点可打；
- 差评归因三分类：产品质量问题 / 履约服务问题（物流、客服）/ 期望落差（宣传过度）；
- 只有期望落差型差评多的竞品 = 详情页夸大，本品可做"实在宣传"差异化。

### 深度口径（引流 review-insight 技能）
用户提供 ≥100 条评论样本时，建议用 review-insight 做主题聚类、情感分布、改进优先级排序。

## 维度四：活动机制拆解

### 促销形式与等效折扣换算
| 形式 | 等效折扣计算 |
|---|---|
| 直降 | 到手价 / 页面价 |
| 满减 | (订单额 − 减免) / 订单额，按典型客单计算 |
| 赠品 | 1 −（赠品零售价合计 / 订单额），注明按零售价还是成本价 |
| 套装 | 套装价 / 单买合计 |
| 会员价/复购券 | 单独列出，判断竞品会员体系强度 |

### 活动节奏分析
1. 大促（618/双11/年货节）：竞品力度、主推 SKU、是否上头部直播间；
2. 日销：常态促销形式（判断品牌是靠机制还是靠内容驱动）；
3. 节奏规律：每月固定会员日 / 上新节奏 / 清仓规律（老品清仓 = 新品上市信号）。

## 威胁等级判定

威胁分 = 价格重叠度（0-3）× 卖点重叠度（0-3）× 声量（0-3，销量+评分+内容声量综合）

| 威胁分 | 等级 | 应对基调 |
|---|---|---|
| ≥ 18 | 高 | 正面防守：价格机制跟进 + 卖点差异化强化 |
| 9–17 | 中 | 侧翼观察：监控其动作，不打正面价格战 |
| < 9 | 低 | 存档跟踪：季度复查即可 |

## 差异化定位三板斧

1. **空白点**：竞品矩阵中无人占据的价格带 × 人群 × 卖点组合；
2. **弱点打击**：竞品差评集中且短期改不了的问题（供应链、配方、服务）；
3. **重新定义**：不与竞品在同一维度对比，改变评价标准（如竞品拼成分浓度，本品拼肤感体验与场景）。

## 信息缺口处理

| 缺失信息 | 替代方法 | 标注方式 |
|---|---|---|
| 竞品到手价 | WebSearch 查大促记录 / 用户提供截图 | 「推断」+ 依据 |
| 竞品销量 | 平台展示销量（月销/累计）/ 第三方数据 | 「平台口径」+ 采集日期 |
| 竞品评价样本 | 平台评论区公开摘要 / 用户导出 | 「抽样」+ 样本量 |
| 竞品成本结构 | 不猜，只分析价格行为 | 标注「无数据」 |
