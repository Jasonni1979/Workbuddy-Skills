# 种草内容矩阵策划

为品牌规划跨平台种草内容矩阵，交付四类产物：内容配比方案、达人层级组合、
月度排期日历、单条内容选题卡。

配比模型与达人分层逻辑见 @references/matrix-framework.md，排期与选题卡骨架见 templates/content-calendar.md。
本技能为纯指令型（不依赖脚本）；所有平台数据由用户提供或 Agent 通过公开检索补充，不编造。

## 第 1 步 确认业务背景

向用户确认：
1. 品牌与品类：决定内容类型侧重（美妆重测评教程、食品重场景、电子重参数演示、服饰重穿搭）；
2. 目标平台与预算：小红书 / 抖音 / 视频号 / B站 / 微博，月度内容预算量级；
3. 营销目标：新品造势 / 日常种草 / 大促蓄水 / 品牌心智，决定配比与节奏；
4. 现有资产：已有账号粉丝量、历史内容表现（爆文率）、已签达人清单；
5. 时间范围：排期覆盖的月份与大促节点。

信息缺失时按 references/matrix-framework.md 的行业默认配比先行，并标注"假设值，待校准"。

## 第 2 步 内容类型配比

按 references/matrix-framework.md 的四象限模型确定配比：

| 内容类型 | 作用 | 典型形式 |
|---|---|---|
| 信任型（测评/对比/成分解析） | 建立专业信任，承接搜索流量 | 测评笔记、红黑榜、成分党长文 |
| 教学型（教程/攻略/使用方法） | 延长停留，沉淀收藏 | 教程视频、攻略图文、Q&A |
| 场景型（生活方式/情绪共鸣） | 破圈拉新，塑造品牌感 | 场景 Vlog、节日主题、人群故事 |
| 促销型（活动/机制/催单） | 收割转化，大促期放大 | 机制解读、限时预告、晒单返场 |

默认配比（日常种草期）：信任 30% / 教学 25% / 场景 30% / 促销 15%；
大促蓄水期把促销提到 30-40%、场景压到 15-20%。品类调整规则见 references/matrix-framework.md。

## 第 3 步 达人层级组合

按预算量级套用金字塔组合（详见 references/matrix-framework.md）：

| 层级 | 角色 | 预算占比参考 | 考核指标 |
|---|---|---|---|
| 头部（>100万粉） | 造势背书，定调性 | 20-30% | 曝光量、搜索指数拉升 |
| 腰部（10-100万粉） | 种草主力，出爆文 | 40-50% | 爆文率、互动成本 CPE |
| 素人/KOC（<10万粉） | 铺量占搜索位，真实感 | 20-30% | 篇数、搜索占位率 |

小预算（<10万/月）跳过头部，腰部+素人为主；大预算（>50万/月）头部锁 1-2 个做 Campaign 定调。

## 第 4 步 月度排期日历

按 templates/content-calendar.md 生成排期表，要求：
- 每周至少覆盖 3 种内容类型，避免单一类型刷屏；
- 大促前 30/15/7 天设置蓄水-引爆-收割三阶段节奏（配合 promo-review 复盘上次大促结论）；
- 新品上市前 2 周开始铺信任型内容（测评/成分），上市当周上促销型；
- 平台差异：小红书搜索长效（内容可复用 3-6 个月）、抖音流量脉冲（跟着热点走）、视频号私域联动（配合 private-domain-sop 的社群转发节点）。

## 第 5 步 选题卡输出

每条重点内容输出选题卡（模板见 templates/content-calendar.md 附节）：
标题（含搜索关键词）、封面构图、内容类型、目标人群、核心卖点（≤3 个）、
CTA、达人层级、预算、发布平台与时间、考核指标。

## 第 6 步 合规红线自查

所有选题卡过一遍红线（详细词库提示用 ad-compliance-check 技能全文扫描）：
1. 广告法极限词：最/第一/顶级等绝对化用语禁用；
2. 种草软广标识：付费合作内容按平台要求标注"赞助"或"广告"；
3. 功效宣称：美妆特证类（祛斑/防晒/防脱）需注册证号支撑，医疗宣称禁用；
4. 虚假测评：不得编造使用体验、伪造对比效果（平台严打"虚假种草"）；
5. 数据引用：销量/用户数据须可验证，标注来源与统计周期。

## 约束

- 不编造平台数据（粉丝量、爆文率、CPE 基准）；无数据时给行业参考区间并标注"假设值"；
- 预算分配只给比例与量级建议，不承诺 ROI 数字；
- 达人推荐只给层级画像与筛选标准，不点名具体账号（避免商业纠纷）；
- 选题卡的卖点表述必须过第 6 步合规自查后才交付；
- 用户提供的品牌资料仅用于本次策划。

## 延伸引导（报告交付后按需提示，每条最多一次）

- 文案成稿后 → 用 ad-compliance-check 做全文合规扫描；
- 单条视频脚本细化 → 用 video-script-planner 出逐秒分镜；
- 竞品内容打法对比 → 用 competitor-review 做活动机制与内容维度拆解；
- 内容带来的私域承接 → 用 private-domain-sop 设计引流话术与频控。
