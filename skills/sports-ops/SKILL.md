# 运动户外行业运营手册

行业参数层技能：为运动/户外/健身/球类品类提供运营基准与专属打法，
并向通用技能层注入行业化参数。运动行业的两个独特资产：
**装备寿命可量化**（跑鞋 500-800km、球拍穿线周期）使复购提醒可以按"使用量"而非"时间"驱动；
**全渠道场景天然完整**（门店体验+电商复购+社群活跃+赛事参与）是 CRM 全渠道运营的最佳样板行业。

完整参数与打法见 @references/industry-playbook.md。本技能为纯指令型，不依赖脚本。

## 第 1 步 确认行业场景

向用户确认：
1. 细分品类：跑步 / 球类 / 健身训练 / 户外登山露营 / 瑜伽 / 骑行 / 综合运动品牌；
2. 渠道结构：纯电商 / 门店+电商 / 门店+电商+社群+赛事（全渠道）；
3. 任务类型：全渠道会员体系 / 装备复购运营 / 赛事营销 / 社群运营 / 大促策略 / 基准对标；
4. 现有数据：全渠道会员/交易/社群数据（有则衔接通用技能实操）。

## 第 2 步 输出行业运营画像

按 references/industry-playbook.md 输出：
1. **装备寿命复购模型**：跑鞋 500-800km（约 6-12 个月）、球拍穿线 3-6 个月、
   瑜伽垫 12-18 个月、户外鞋服按磨损；复购提醒按"购买日期+品类寿命"或"用户上报里程"驱动；
2. **全渠道会员一体化**：门店首购+电商复购+社群活跃+赛事参与四类行为统一积分与分层，
   识别"高活跃低消费"（社群 KOC 候选）与"高消费低活跃"（流失预警）两类特殊人群；
3. **场景人群分层**：专业竞技 / 严肃业余 / 大众健身 / 潮流穿搭（运动时尚）四层，
   内容与货品策略完全不同；
4. **基准指标**：复购率、连带率（鞋+服+配件）、退货率（尺码/脚型）、社群活跃转化。

## 第 3 步 行业参数注入通用技能（核心价值）

| 通用技能 | 运动参数替换 |
|---|---|
| member-lifecycle-calendar | **寿命驱动替代时间驱动**：跑鞋复购提醒=购买+9 个月（或里程上报 500km）；穿线提醒=3-6 个月；增补节点：赛事报名季（马拉松春秋两季前 60 天装备焕新）、季节切换（夏跑/冬跑装备）、社群打卡里程碑（连续 30 天→装备升级券） |
| crm-analytics | 全渠道行为合并：门店/电商/社群/赛事四源打标签；分层增补"运动强度"（周跑量/训练频次）与"装备代际"（当前跑鞋代数）；CLV 按"装备+ apparel +配件"三篮计算 |
| inventory-alert | 季节性双峰备货（春秋跑季/夏泳/冬雪）；尺码深度管理（跑鞋半码齐全是体验红线，断半码=断货）；过季 apparel 按服饰清货逻辑、装备类按耐用品长周转 |
| promo-review | 增补维度：全渠道归因（门店体验→电商成交链路）、赛事期销售脉冲、社群活动 ROI、连带率（三篮结构） |
| review-insight | 主题库预置：脚型/尺码偏差（跑鞋最高频）、磨脚/支撑不足、做工（开胶/线头）、功能性落差（缓震/回弹与宣传不符→P1，涉虚假宣传升 P0）、物流 |
| ad-compliance-check | 功能性宣称须检测依据（缓震回弹率/压缩等级/防水指数）；"专业比赛级/冠军同款"须授权或事实；碳板等科技宣称不夸大疗效类表述（如"防伤"属医疗暗示 P0） |
| competitor-review | 对比重点：科技平台（中底科技矩阵）、赛事赞助与运动员代言、社群规模与活跃、全渠道体验 |
| video-script-planner | 内容角度：实测（跑步机/路面里程测试）、场景（晨跑/越野/健身房）、素人打卡故事；禁用"治病/防伤"表述 |
| ecom-daily-report | 增补指标：全渠道 GMV 拆分、社群引流成交占比、赛事期脉冲系数 |

## 第 4 步 行业红线自查

- 功能性宣称（缓震/回弹/压缩/防护）须检测报告，"防伤病"属医疗暗示 P0；
- "冠军同款/国家队装备"须授权证明，无授权 P0；
- 儿童运动装备另有安全标准，涉童装童鞋提示单独核查；
- 社群/赛事活动安全提示（户外线路风险告知）属品牌责任，内容输出须含安全声明；
- 不鼓励过度训练表述（"每天 30km 不伤膝"类）——健康误导风险。
