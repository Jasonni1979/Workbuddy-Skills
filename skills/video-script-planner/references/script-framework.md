# 短视频脚本框架与钩子库

> 适用：30-60 秒带货/种草/科普短视频（抖音/视频号/小红书）。
> 原则：前 3 秒定生死；卖点必须可视化；口播口语化；受限品类内置合规自查点。

## 一、黄金结构

### 30 秒版

| 段落 | 时间 | 任务 | 要点 |
|---|---|---|---|
| 钩子 | 0-3s | 留住手指 | 产品特写或冲突画面+一句钩子台词；禁止 logo 开场 |
| 痛点/悬念 | 3-8s | 建立相关 | 说出目标人群的痛或好奇点，"你是不是也…" |
| 卖点演绎 | 8-22s | 证明 | 2-3 个卖点，每个配一个可视化动作（倒/切/对比/微距/上手） |
| 信任背书 | 22-26s | 消除顾虑 | 产地/工艺/检测/口碑/销量（须真实，缺则占位符） |
| CTA | 26-30s | 转化 | 价格锚点+行动指令（点购物车/进直播间/关注看下集） |

### 60 秒版

钩子(0-3) → 痛点(3-10) → 场景代入(10-18) → 卖点演绎×3-4(18-44) → 背书(44-52) → CTA(52-60)。

## 二、钩子库（选后必须改写，禁止照抄）

| 类型 | 模板 | 适用品类 |
|---|---|---|
| 反常识 | "XX 居然不能这样喝/用" | 酒类/美妆/食品 |
| 价格锚点 | "专柜 XX 的同厂，只要 1/3 价" | 有供应链故事时（须真实） |
| 身份认同 | "30 岁以后才懂的 XX" | 威士忌/护肤/茶 |
| 悬念物件 | 只拍局部特写不揭示全貌 3 秒 | 高颜值产品 |
| 冲突开场 | 两个杯子/两款产品对撞 | 对比测评类 |
| 数字清单 | "3 个信号说明你的 XX 该换了" | 科普/替换型消费 |
| 场景沉浸 | 环境音先行（冰块声/雨声/键盘声） | 酒类/家居/办公 |
| 提问互动 | "你能猜出这瓶多少年吗" | 收藏/年份类 |

## 三、卖点可视化动作库

| 卖点 | 可视化动作 |
|---|---|
| 酒体/色泽 | 逆光举杯微距、挂杯慢镜、冰块入杯声 |
| 质地（美妆） | 手背推开、滴管慢滴、吸油纸对比 |
| 口感/风味 | 三层风味字幕卡（前调/中调/尾调）+ 表情反应 |
| 工艺 | 产线/原料空镜 + 数字字幕（年份/温度/时长） |
| 性价比 | 单价换算字幕（"一杯=XX 元"） |
| 便携/设计 | 开合动作、口袋入镜、磁吸声 |

## 四、品类红线自查点（输出前逐条核对）

| 品类 | 红线 | 脚本处理 |
|---|---|---|
| 酒类 | 不宣称健康功效、不诱导过量、不出现未成年人、不驾驶场景 | 片尾加"理性饮酒 未成年人禁止饮酒"字幕位；场景限独酌/佐餐/礼赠 |
| 保健/食品 | 不宣称疾病治疗/预防 | 功效词替换为体验词 |
| 美妆 | 特证功效（美白/防脱）需证号 | 无证改体验表述 |
| 全品类 | 绝对化用语、贬低竞品、虚假背书 | 过 ad-compliance-check 口径 |

## 五、选题发散法（无选题时给 3 张候选卡）

每张卡含：角度（知识/场景/对比/故事/清单 五选三发散）、钩子类型、卖点排序（主打 1+辅 2）、
预期人群、预期完播风险点（哪一秒容易划走及对策）。

## 六、节奏与转场建议

- 平均镜头时长：30s 视频 ≤2.5s/镜（约 12-14 镜）；60s ≤3s/镜；
- 转场：硬切为主（快），卖点切换用匹配剪辑（同构图换物），段落切换用推拉；
- BGM：钩子段静音或环境音突出台词，卖点段起节奏，CTA 段收；
- 字幕：关键词大字+价格锚点常驻右下角；口播字幕小字底部。
