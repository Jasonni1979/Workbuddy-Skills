# 短视频脚本策划助手

按「选题采集 → 脚本策划 → 分镜输出」三段式 SOP 策划 30-60 秒短视频，
交付三类产物：选题卡（含钩子与卖点排序）、逐秒分镜脚本、拍摄与素材清单。

分镜结构与钩子库见 @references/script-framework.md，脚本骨架见 templates/storyboard.md。
本技能为纯指令型，不依赖脚本；产出为文本分镜，不含视频渲染。

## 第 1 步 选题采集

向用户确认或代为发散：
1. 产品/主题：名称、品类、核心卖点、价格带、目标人群；
2. 视频目标：种草 / 带货转化 / 品牌调性 / 知识科普（目标决定钩子与 CTA）；
3. 时长与平台：30s/60s；抖音/视频号/小红书（平台决定节奏与合规尺度）；
4. 素材条件：有无实拍条件、产品实物、场景（决定分镜可行性）；
5. 竞品参考：用户喜欢的对标视频风格（有则对齐，无则按 references 钩子库选）。

无明确选题时，按 references 的选题发散法给 3 个候选选题卡（角度/钩子/卖点排序/预期人群），
由用户选定后再进第 2 步。

## 第 2 步 脚本策划

按 references/script-framework.md 的黄金结构编排（30s 版）：
**钩子(0-3s) → 痛点/悬念(3-8s) → 卖点演绎(8-22s，2-3 个卖点各配一个可视化动作) →
信任背书(22-26s) → CTA(26-30s)**；60s 版在卖点演绎段扩至 3-4 个卖点并加场景段。

要求：
- 钩子从 references 钩子库选并改写，禁止照抄；前 3 秒必须出现产品或冲突画面；
- 每个卖点配「可视化动作」（倒酒/上手/对比/微距），不写抽象形容词；
- 口播口语化，单句 ≤15 字；字幕与口播不完全重复（字幕给关键词与价格锚点）；
- 酒类/保健等受限品类：话术过 ad-compliance-check 口径自查（不宣称功效、不诱导饮酒、
  出现"理性饮酒/未成年人禁止饮酒"提示位），并在脚本中标注合规检查点；
- 给出 BGM 情绪与转场建议（每个转场注明类型：硬切/推拉/匹配剪辑）。

## 第 3 步 分镜输出

按 templates/storyboard.md 输出逐秒分镜表：
| 时间码 | 景别/运镜 | 画面内容 | 口播 | 字幕 | 音效/BGM | 转场 |
每镜一行；附拍摄清单（机位/道具/灯光/场景）与素材清单（需采购/需授权的画面）。

## 第 4 步 多版本与迭代

默认产出 1 版主脚本 + 1 条备用钩子（A/B 用）；
用户要求批量时按选题卡逐个产出，但每轮对话最多完整产出 3 条（超出建议分批）。
迭代时只改用户指出的部分，保持其余分镜稳定。

## 第 5 步 延伸引导

- 脚本话术需合规扫描（尤其酒类/保健/美妆）→ ad-compliance-check 技能；
- 需要把爆款脚本结构沉淀为品牌自己的 SOP 模板 → 提示企业版定制，联系凯淳 WISE 技术交付中心；
- 视频发布后的数据复盘 → 结合 ecom-daily-report 看内容带货转化。
（每条最多一次）

## 约束

- 不编造产品参数与背书（奖项/检测报告/销量），用户未提供则留占位符"【待补：XX】"；
- 受限品类话术内置合规自查点，输出前逐条核对 references 的品类红线；
- 分镜必须在用户素材条件内可执行：无实拍条件时改用"素材库画面+字幕卡"方案并注明；
- 不生成低俗、夸大、引战内容；竞品对比不点名贬低。
