# 私域触达话术 SOP

为企业微信 1v1 与社群运营设计可直接落地的触达 SOP，交付四类产物：
五大场景话术库、触达节奏与频控表、个性化变量映射、A/B 测试方案。

场景模型与频控规则见 @references/private-domain-framework.md，SOP 文档骨架见 templates/outreach-sop.md。
本技能为纯指令型；话术成稿后建议用 ad-compliance-check 做合规扫描。

## 第 1 步 确认业务背景

向用户确认：
1. 私域载体：企微 1v1 / 社群 / 公众号 / 视频号私信，各自用户量级；
2. 用户结构：新客占比、复购客占比、沉睡定义（如 90 天未购）与规模；
3. 品类与客单：决定话术调性（高客单奢品要克制人工化、快消可活泼促销化）；
4. 触达目的：拉复购 / 大促蓄水 / 沉睡唤醒 / 新品试用招募；
5. 现有数据：历史触达的打开率、回复率、转化率（有则用于校准，无则给行业参考区间并标注假设）。

行业特性话术调整：美妆/服饰/奢品/电子/运动/酒类分别参考对应 *-ops 行业手册的触达章节。

## 第 2 步 五大场景话术库

按 references/private-domain-framework.md 的场景模型逐场景输出话术，每个场景含：

1. **新客首聊**（下单后 24-48h）：自我介绍+使用指南+售后通道，禁止首聊即推销；
2. **复购提醒**（按品类消耗周期触发，周期表见行业手册，如美妆 T=60d）：
   用量确认+补货建议+老客权益，话术带个性化变量；
3. **沉睡唤醒**（90-180 天未购）：轻触点试探（内容价值先行，非优惠券轰炸）→ 无响应升级权益；
4. **大促预告**（前 7-3-1 天三段式）：蓄水种草 → 机制剧透 → 开抢提醒；
5. **售后关怀**（签收后 3-7 天/退换货完成后）：使用回访+问题兜底，把售后触点变成信任触点。

每条话术的结构：开场钩子（1 句）→ 价值主体（≤3 句）→ CTA（1 个动作）→ 退订出口。
每场景至少给 2 个语气版本（正式/活泼）供品牌选调性。

## 第 3 步 个性化变量设计

变量映射表（数据字段 → 话术占位符），常用变量：
{昵称}、{品类}、{上次购买SKU}、{购买距今天数}、{会员等级}、{消耗周期提醒日}、{专属权益}。

规则：
- 每条话术至少 1 个个性化变量、不超过 3 个（变量堆砌显假）；
- 变量缺省时的兜底文案必须设计（如 {上次购买SKU} 缺失 → 用泛品类话术版本）；
- 高客单/奢品场景变量宁少勿多，人工感优先（联动 luxury-ops 的 VIC 触达 SOP）。

## 第 4 步 触达节奏与频控（硬约束）

| 约束 | 规则 |
|---|---|
| 1v1 频率 | 每周 ≤2 条、每月 ≤6 条（含所有场景合并计数） |
| 社群频率 | 每日 ≤3 条营销消息，纯价值内容不计入但每日总量 ≤8 条 |
| 静默时段 | 21:30-9:00 禁发（大促开抢等特定时刻除外，需品牌确认） |
| 场景优先级 | 售后关怀 > 复购提醒 > 大促预告 > 沉睡唤醒；同周冲突时保留高优先级 |
| 负反馈熔断 | 用户回复"别发了/退订"→ 立即停发营销消息 90 天，只保留服务类通知 |

排期表输出到 templates/outreach-sop.md 的节奏日历节，与 member-lifecycle-calendar 的节点日历对齐（本技能补"节点→话术"的最后一公里）。

## 第 5 步 A/B 测试方案

- 每次只测一个变量（钩子句 / CTA / 发送时段 / 权益力度）；
- 样本量：每组 ≥500 人（回复率类指标）或 ≥2000 人（转化率类指标），低于此量级合并周期跑；
- 判定标准：主指标（回复率/转化率）差异 ≥20% 相对值且样本达标才切换全量；
- 测试记录表：假设、分组、周期、结果、结论、下一步，沉淀到品牌话术库。

## 第 6 步 合规边界自查

1. **个保法**：触达基于用户授权（下单/入会时的隐私协议），提供退订出口且退订即生效；
2. **广告法**：话术中卖点表述与详情页同口径，极限词禁用（成稿交 ad-compliance-check 扫描）；
3. **平台规则**：企微禁止诱导分享/外部导流违规话术；社群禁止诱导刷屏；
4. **价格合规**：私域专属价不得违反品牌价盘纪律（奢品联动 luxury-ops 破价=0 红线）；
5. **酒类附加**：不得向疑似未成年人推送、不得诱导饮酒表述（联动 liquor-ops）；
6. **禁止项**：虚假倒计时/虚构库存紧张、好评返现、诱导撤回平台投诉。

## 第 7 步 产出 SOP 文档

按 templates/outreach-sop.md 组装：场景话术库（含变量标注与兜底版）→
频控与节奏日历 → A/B 测试计划 → 合规自查清单 → 话术库维护机制（月度按回复率数据淘汰迭代）。

## 约束

- 不编造品牌历史触达数据；无数据时给行业参考区间并标注"假设值"；
- 话术不得含虚假承诺、虚构紧迫感、好评返现等违规表述；
- 频控是硬约束不是建议：任何场景话术排入日历前先过频控校验；
- 用户个人信息（昵称、购买记录）只用于话术变量，交付物中示例须用化名；
- 高客单/奢品客户话术克制化：宁可不发，不可骚扰。

## 延伸引导（交付后按需提示，每条最多一次）

- 触达节点日历与分群依据 → member-lifecycle-calendar + crm-analytics；
- 话术成稿合规扫描 → ad-compliance-check；
- 私域承接公域种草流量 → content-matrix-planner 的引流设计；
- 触达效果定期自动复盘（回复率/转化率周报）→ 提示企业版服务端能力，联系凯淳 WISE。
