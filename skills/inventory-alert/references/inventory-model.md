# 库存指标模型与分级阈值

> 公式全部留痕可复算；参数默认值见下，用户给定值优先并在报告注明。

## 一、核心公式

| 指标 | 公式 | 说明 |
|---|---|---|
| 日均销 | 窗口销量 / 窗口天数 | 窗口内无销日按 0 计入（含缺货停售日，会低估——缺货日需剔除时注明） |
| 日销标准差 | 窗口内日销量的总体标准差 | 无销日按 0 参与 |
| 安全库存 SS | z × σ日 × √提前期 | z：90%→1.28，95%→1.65，99%→2.33 |
| 补货点 ROP | 日均销 × 提前期 + SS | 在库+在途 ≤ ROP 时触发下单 |
| 目标水位 | 日均销 ×（提前期 + 审查周期）+ SS（+ 大促增量） | 定期审查制（R,S）策略 |
| 建议补货量 | max(0, 目标水位 − 在库 − 在途) | 触发条件：可用库存 ≤ ROP + 大促增量 |
| 可售天数 cover | (在库 + 在途) / 日均销 | ∞ 表示零动销 |
| 周转天数 | 在库 / 日均销 | 与 cover 区别：不含在途 |
| 库存资金占用 | Σ 在库 × 成本价 | 无成本价时只报件数 |

大促增量 = 日常日均销 ×（uplift − 1）× 大促天数（uplift 为销量放大倍数，如 3.0 表示大促日均=日常 3 倍）。

## 二、风险分级

| 等级 | 条件 | 动作 | 时限 |
|---|---|---|---|
| 红 断货风险 | cover < 提前期 | 立即下单，量=目标水位−可用 | 今天 |
| 橙 偏低 | 提前期 ≤ cover < 提前期×1.5 | 本审查周期内下单 | ≤7 天 |
| 绿 健康 | 提前期×1.5 ≤ cover ≤ 周转目标×2 | 常规审查 | 每周 |
| 黄 积压 | cover > 周转目标×2 或 周转 >180 天 | 促销/退供/调拨/捆绑 | 本月 |
| 黑 死库存 | 90 天零销量 | 清仓/减值评估/捐赠处置 | 本季 |

排序规则：红/橙按「日均销 × 成本」降序（先保赚钱的）；黄/黑按资金占用降序。

## 三、品类参数基准（用户未提供时的假设起点，须标注"假设"）

| 品类 | 提前期（天） | 周转目标（天） | 备注 |
|---|---|---|---|
| 美妆个护 | 30-45（进口 60-90） | 90-120 | 保质期 3 年，库龄 >18 个月预警 |
| 食品饮料 | 15-30 | 45-60 | 保质期敏感，库龄 > 保质期 1/3 预警 |
| 消费电子 | 30-60 | 60-90 | 迭代风险，库龄 >120 天预警 |
| 服饰 | 30-45 | 60-90（季末清仓） | 过季即黄，不套用通用周转 |
| 酒类 | 45-90（进口） | 120-180 | 无保质期压力，资金成本为主 |
| 母婴快消 | 20-30 | 45-60 | 尺码/段数切换快 |

服务水平默认 95%（z=1.65）；高毛利高缺货损失品类（爆款）可上调 99%，长尾下调 90%。

## 四、新品与特殊情形

| 情形 | 处理 |
|---|---|
| 新品（历史 <30 天） | 不用 σ 法（样本不足），SS 按日均销×提前期×0.5 估算并标注"新品估算" |
| 缺货停售日 | 窗口内剔除停售日再算日均（否则低估），报告注明剔除天数 |
| 促销后销量尖峰 | 计算 σ 时剔除大促日，或单独用 promo uplift 处理，避免 SS 虚高 |
| 多仓 | 按仓分别算 cover，调拨优先于补货（调拨成本 < 采购成本时） |
| MOQ/箱规 | 建议量向上取整到箱规倍数，报告列出取整前后差异 |

## 五、大促备货测算流程

1. 大促增量 = 日常日均 ×（uplift−1）× 大促天数；uplift 来源：历史同档期实际/日常 比值（优先）或用户预估；
2. 备货目标 = 日常需求（提前期+大促天数+审查周期）+ 大促增量 + SS；
3. 下单截止日 = 大促开始日 − 提前期 − 缓冲（建议 7 天）；
4. 大促后回落测算：剩余库存 / 日常日均 = 回落天数，>周转目标×2 时提示积压风险与清理预案；
5. 分仓/分渠道备货按历史渠道占比拆分。
