# 轻奢奢品行业运营手册

行业参数层技能：为轻奢/奢品/高端珠宝腕表/设计师品牌提供运营基准与专属打法，
并向通用技能层注入行业化参数。奢品的核心矛盾与大众品类相反：
**大众品类追求转化率与规模，奢品追求稀缺感与客户终身价值**——
折扣是品牌毒药，VIC（高净值客户）贡献远超流量运营，私域服务重于公域投放。

完整参数与打法见 @references/industry-playbook.md。本技能为纯指令型，不依赖脚本。

## 第 1 步 确认行业场景

向用户确认：
1. 定位层级：真奢（万元+）/ 轻奢（2000-10000）/ 高端设计师（1000-5000）/ 珠宝腕表；
2. 渠道结构：精品店 / 天猫奢品（Luxury Pavilion）/ 京东奢品 / 小程序私域 / 买手店；
3. 任务类型：VIC 运营 / 价格体系管理 / 私域服务设计 / 大促策略（奢品语境）/ 基准对标；
4. 现有数据：会员/交易/服务记录（有则衔接通用技能实操）。

## 第 2 步 输出行业运营画像

按 references/industry-playbook.md 输出：
1. **价格纪律**：全年折扣深度上限、大促参与方式（赠品/服务权益替代直降）、
   渠道价差管理与窜货防治；
2. **VIC 运营**：VIC 定义线（年消费/单客贡献）、1-5-10% 客户贡献结构、
   一对一 clienteling 服务 SOP、专属权益体系；
3. **礼赠场景**：奢品 GMV 的礼赠占比（30-50%）、节点日历（情人节/520/七夕/圣诞/生日）、
   礼盒与刻字服务运营；
4. **基准指标**：客单、年复购率、VIC 贡献占比、毛利结构、退货率（奢品显著低于大众）。

## 第 3 步 行业参数注入通用技能（核心价值）

| 通用技能 | 奢品参数替换 |
|---|---|
| member-lifecycle-calendar | T 概念弱化，改"关系里程碑"驱动：首购周年、VIC 晋级、生日（最高优先级）、礼赠节点；触达渠道以企微一对一为主、短信为辅，**禁用高频轰炸式 Push**；频控收紧至每月 ≤3 次 |
| crm-analytics | CLV 是核心指标（客单高、频次低）；分层线提高：VIC 年消费 ≥5 万（轻奢 ≥2 万）；RFM 中 F 权重降低、M 权重提高；增补礼赠行为标签（代买/刻字/礼盒） |
| inventory-alert | 经典款永续补货、季节款控量；周转目标放宽至 120-180 天（稀缺性容忍库存）；限量款不按售罄率考核（故意留稀缺）；库龄红线放宽但款式退市管理严格 |
| promo-review | 奢品大促逻辑不同：复盘"权益成本"而非"折扣深度"；增补维度：VIC 参与率、礼赠占比变化、新客质量（首购客单）、价格体系完整性（有无破价记录） |
| ad-compliance-check | 增补红线：原产地/工艺宣称须与备案一致、"限量"须真实（数量可证）、代言人合规、二手/中古转售表述、鉴定证书宣称 |
| review-insight | 主题库预置：正品疑虑（最高敏感）、五金/走线工艺、客服响应速度、包装仪式感、专柜与线上体验差异 |
| competitor-review | 对比重点：价格体系稳定性（谁先破价）、VIC 权益设计、限量发售节奏、渠道授权结构 |
| video-script-planner | 内容调性：工艺细节微距、品牌故事、场景身份认同；禁用叫卖式钩子与价格锚点开场；CTA 改"预约到店/专属顾问" |

## 第 4 步 行业红线自查

- **价格红线**：任何建议不得导致公开渠道破价（低于品牌最低限价）；大促机制优先赠品/服务权益/分期免息，直降仅限奥莱与员工内购渠道；
- **正品与鉴定**：不承诺"支持任何形式的第三方鉴定"除非品牌官方认可；二手流转表述谨慎；
- **限量宣称**：数量必须真实可证，"限量"后补货即虚假宣传；
- **VIC 数据**：高净值客户信息是最敏感资产，输出物中只到分层粒度，绝不出现个体明细；
- **产地与工艺**：原产地、手工工艺、材质宣称须与产品备案/证书一致（如"瑞士机芯""意大利手工"须有依据）。

## 约束

- 一切建议以"不破坏价格体系与稀缺感"为前提，与大众品类打法冲突时以本手册为准；
- 基准数字标注"行业基准区间（公开经验值）"；
- VIC 个体信息零输出（只到分层粒度）；
- 用户数据仅用于本次分析。
