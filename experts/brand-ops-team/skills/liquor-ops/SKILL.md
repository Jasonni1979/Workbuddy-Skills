# 酒类行业运营手册

行业参数层技能：为白酒/威士忌/葡萄酒/啤酒/黄酒品类提供运营基准与专属打法，
并向通用技能层注入行业化参数。酒类是**监管最严+场景最特殊**的品类：
广告法对酒类有专门条款（禁诱导饮酒、禁驾驶场景、禁未成年人），健康宣称一律禁止；
同时消费场景高度集中（礼赠/宴请/收藏/自饮小酌），年份与产地宣称受强监管，
白酒有独特的渠道控盘体系，威士忌有收藏稀缺逻辑。

完整参数与打法见 @references/industry-playbook.md。本技能为纯指令型，不依赖脚本。
（本手册沉淀自凯淳 WISE 威士忌短视频与酒类品牌服务经验。）

## 第 1 步 确认行业场景

向用户确认：
1. 细分品类：白酒 / 威士忌 / 葡萄酒 / 啤酒 / 黄酒 / 预调酒；
2. 价格带与定位：大众口粮 / 中端宴请 / 高端礼赠 / 收藏级；
3. 任务类型：礼赠营销 / 收藏会员运营 / 年份宣称合规 / 渠道价格管控 / 复购运营 / 内容策划 / 基准对标；
4. 现有数据：会员/交易数据（有则衔接通用技能实操）。

## 第 2 步 输出行业运营画像

按 references/industry-playbook.md 输出：
1. **场景四分**：礼赠（白酒 40-60%/威士忌 30-50%）、宴请（白酒主导）、收藏（威士忌/高端白酒）、自饮小酌（威士忌/葡萄酒/精酿）——四场景人群、货品、内容完全不同；
2. **饮用周期复购**：700ml 威士忌自饮 2-4 个月、白酒宴请按宴席周期、啤酒夏季高频；复购提醒按"容量/饮用频率"估算；
3. **合规红线**：广告法酒类条款全量启用（见第 4 步），任何内容输出前必查；
4. **基准指标**：礼赠占比、复购率、收藏款溢价率、渠道价差。

## 第 3 步 行业参数注入通用技能（核心价值）

| 通用技能 | 酒类参数替换 |
|---|---|
| member-lifecycle-calendar | 双驱动：自饮按容量周期（威士忌 700ml≈3 个月）+ 礼赠按节点（春节/中秋/端午前 30-45 天）；增补节点：收藏款发售日（限量预约）、开瓶周年（"您去年今日入手 XX"情感触达，威士忌收藏圈有效）；频控收紧（酒类营销敏感，每月 ≤3 次） |
| crm-analytics | 分层增补"场景标签"（礼赠/宴请/收藏/自饮）与"品类偏好"（产区/香型/年份）；收藏客单独成层（CLV 极高、频次低）；礼赠行为标签（代买/礼盒/贺卡）同奢品逻辑 |
| inventory-alert | 白酒：控盘分利体系下库存=渠道压货，关注经销商库存周转而非零售库存；威士忌：限量款稀缺管理（不补货）、常规款长周转（180-360 天可接受）；葡萄酒：年份更替管理（新年份上市旧年份清尾）、存储条件敏感 |
| promo-review | 增补维度：礼赠占比变化、宴席场次归因（扫码开瓶数据）、收藏款溢价与二级市场表现、渠道价差与窜货 |
| review-insight | 主题库预置：真伪疑虑（酒类最高敏感，无条件 P0）、漏液/包装破损（物流）、口感与预期落差（批次差异）、年份/标识与实物不符（P0 虚假宣传）、物流保价 |
| ad-compliance-check | 广告法酒类条款全量启用：禁诱导饮酒/禁驾驶与未成年人场景/禁健康功效宣称/须"理性饮酒"提示；年份与产地宣称须与备案一致 |
| competitor-review | 对比重点：价格带卡位与控盘力度、限量发售节奏、宴席政策（开瓶扫码奖励）、收藏圈口碑 |
| video-script-planner | 内容调性：品鉴仪式（观色/闻香/品味三段）、产地故事、收藏价值叙事；强制合规自查：理性饮酒字幕位、无驾驶/劝饮/未成年场景、无健康宣称 |
| ecom-daily-report | 增补指标：礼赠订单占比、开瓶扫码率（宴席归因）、限量款售罄速度 |

## 第 4 步 行业红线自查（输出任何内容前必查，最高优先级）

**广告法酒类专门条款（第十六条等）**：
- 不得诱导、怂恿饮酒或宣传无节制饮酒（"不醉不归""豪饮挑战"类 P0）；
- 不得表现驾驶车船等危险场景，不得暗示饮酒消除紧张/提升体力（广告法第十六条，P0）；
- 不得出现未成年人形象或向其营销（P0）；
- 拍摄尺度：广告法未明文禁止倒酒/举杯画面，但主流平台（抖音/视频号）审核禁止"吞咽饮酒动作"特写——电商短视频从严执行：拍倒酒/举杯/闻香/观色，不拍吞咽（P1，平台下架风险）；
- 不得宣称健康功效（"活血""养胃""助眠"一律 P0，保健酒也仅限批号内功能）；
- 所有酒类内容须带"理性饮酒/未成年人禁止饮酒"提示位（视频片尾字幕、详情页固定位）。

**年份与产地宣称**：
- 威士忌年份=最年轻基酒酒龄（"15 年"指最年轻基酒 15 年），无年份 NAS 不得暗示具体年份；
- 白酒"XX 年陈酿/窖藏"须有依据（基酒比例/储存记录），"年份酒"标注规范按行业标准；
- 产区宣称（苏格兰/干邑/茅台镇核心产区）须与产地证明一致；
- "单一麦芽/纯粮固态"等工艺宣称须符合定义与检测。

**渠道与价格**：
- 白酒控盘分利：建议不破出厂价体系，窜货与低价倾销是渠道红线；
- 跨境电商品类限制（威士忌保税/直邮资质）、酒类流通许可（线上销售需食品经营许可含酒类）；
- 直播卖酒：平台资质要求+话术红线（不劝饮、不拼酒、不健康宣称）。

## 约束

- 合规红线高于一切营销目标：任何建议与广告法酒类条款冲突时以合规为准；
- 基准数字标注"行业基准区间（公开经验值）"；
- 年份/产地/工艺宣称保守化：拿不准按"需证明"处理，留"【待补：证明】"占位；
- 不输出任何可能被解读为诱导饮酒或面向未成年人的内容；
- 用户数据仅用于本次分析。
