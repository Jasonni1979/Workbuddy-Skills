# 日报指标口径与异动归因方法

## 一、指标口径（报告必须标注）

| 指标 | 公式 | 口径说明 |
|---|---|---|
| GMV | Σ 支付金额 | 支付口径，不扣退款 |
| 净 GMV | GMV − 退款 | 需要时才展示 |
| 订单量 orders | Σ 支付订单数 | |
| 客单价 AOV | GMV / orders | |
| 件单价 | GMV / qty | 与 AOV 区分（连带率 = qty/orders） |
| 转化率 CVR | orders / uv | uv 为访客去重口径；跨平台不加总 |
| 退款率 | refund / GMV | 按退款成功日归期 |
| 月目标进度 | MTD GMV / 月目标 | |
| 时间进度 | 已过天数 / 当月天数 | |
| 进度差 | 目标进度 − 时间进度 | 负值=落后，日报首屏必报 |

同环比基数为 0 → 标注"基数为零"，不输出百分比；同比缺失 → 该列省略。

## 二、异动归因树（触发阈值默认 |环比|>15%）

```
GMV 异动
├─ 量价拆解: ΔGMV ≈ Δorders 贡献 + ΔAOV 贡献（乘法分解取对数近似或逐项替代法）
│   ├─ orders 异动
│   │   └─ 漏斗拆解: orders = uv × CVR → 定位流量 or 转化
│   │       ├─ uv 异动 → 渠道结构拆解（各渠道 uv 增量贡献）→ 事件核对（投放/直播/活动上下线）
│   │       └─ CVR 异动 → 结构（渠道/类目 mix）or 单渠道转化 → 事件核对（价格/券/详情页/缺货/差评）
│   └─ AOV 异动 → 类目 mix / 连带率 / 券力度 / 套装占比
└─ 结构拆解: 各渠道(类目)增量 / 总增量 → 主驱动与主拖累 TOP2
```

逐项替代法（推荐，可加总）：
- 订单贡献 = (orders_cur − orders_prev) × AOV_prev
- 客单贡献 = (AOV_cur − AOV_prev) × orders_cur
- 两者之和 = ΔGMV（精确）。

## 三、事件核对清单（归因最后一层）

| 事件类型 | 数据来源 | 缺失时处理 |
|---|---|---|
| 大促/活动档期 | 用户提供活动日历 | 标注"事件因素待确认" |
| 直播排期 | 用户提供 | 同上 |
| 券/价格调整 | 用户提供 | 同上 |
| 缺货/断货 | inventory-alert 断货清单 | 提示联动查询 |
| 差评/舆情 | review-insight | 提示联动查询 |
| 平台规则/流量分配变化 | 不可得 | 列入待确认 |

归因输出格式：现象（指标+幅度）→ 拆解（量/价、流量/转化、渠道贡献）→ 事件（已确认/待确认）。
**确定性结论与假设必须分开写**，假设进"待确认清单"。

## 四、日报首屏五要素

1. 昨日 GMV 与环比；
2. 月目标进度 vs 时间进度（进度差）；
3. 最大异动指标一句话归因；
4. 渠道结构最大变化一句话；
5. 今日关注 ≤3 条（可执行）。

## 五、周报增量模块

- 7 日趋势表（GMV/orders/CVR 逐日）；
- 周度结构变化（渠道占比本周 vs 上周）；
- 周内最佳/最差日及原因；
- 下周关注（结合活动日历与库存/口碑联动结论）。

## 六、常见误读防护

1. 大促日环比必然暴涨暴跌 → 大促期改用"vs 上一档期同日"或"vs 目标"为主对比；
2. 周一效应/周末效应 → 日报环比同时附"vs 上周同 weekday"；
3. 退款滞后 → 退款率突增先查是否批量审核退款，而非产品质量；
4. uv 口径变化（平台改版）→ 转化率突变先核对口径公告。
