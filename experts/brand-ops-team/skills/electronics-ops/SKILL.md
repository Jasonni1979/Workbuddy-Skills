# 消费电子行业运营手册

行业参数层技能：为消费电子/3C 数码/智能硬件/小家电品类提供运营基准与专属打法，
并向通用技能层注入行业化参数。消费电子的核心矛盾是**迭代贬值与技术信任**——
主机低频高客单、毛利薄，真正的利润线在配件耗材与服务（延保/以旧换新）；
参数宣称受强监管（3C 认证、检测报告），虚假参数是最高风险红线。

完整参数与打法见 @references/industry-playbook.md。本技能为纯指令型，不依赖脚本。

## 第 1 步 确认行业场景

向用户确认：
1. 细分品类：手机/电脑 / 影音穿戴 / 智能家居 / 小家电 / 配件周边；
2. 品牌角色：品牌方 / 授权经销商 / 白牌工厂（决定价格管控能力与合规责任）；
3. 任务类型：新品上市 / 生命周期管理 / 参数合规 / 配件复购设计 / 以旧换新 / 大促策略 / 基准对标；
4. 现有数据：销售/会员/售后数据（有则衔接通用技能实操）。

## 第 2 步 输出行业运营画像

按 references/industry-playbook.md 输出：
1. **生命周期节奏**：旗舰机型 12 个月大迭代 + 6 个月中期改款；
   上市期（首发权益）→ 正价期（3-6 月）→ 促销期（大促降价）→ 清尾期（下代发布前 2 个月）；
2. **利润结构**：主机毛利 5-15%（引流品），配件耗材毛利 30-60%（利润品），
   服务收入（延保/换新/订阅）是第三曲线；
3. **参数合规**：3C 强制认证、性能参数须有检测报告、"防水等级/续航/像素"等宣称须标测试条件；
4. **基准指标**：客单、复购率（主机低配件高）、退货率、价保投诉率。

## 第 3 步 行业参数注入通用技能（核心价值）

| 通用技能 | 消费电子参数替换 |
|---|---|
| inventory-alert | **贬值型库存逻辑**：库龄 >90 天黄牌（下代发布即贬值 20-30%）、>180 天黑牌；新品上市前 60 天上代产品停止补货进入清尾；配件耗材按快消逻辑（T=60-90 天）单独管理；大促 uplift 集中在大促与新品首发 |
| member-lifecycle-calendar | 主机 T=365 天+，实际驱动节点：**配件耗材周期**（滤芯 90d/表带 180d/墨盒 60d）+ 新品发布日（老客以旧换新邀约）+ 延保到期前 30 天（续费节点）+ 首发权益日；换机提醒在下代发布前 30 天触发 |
| crm-analytics | 分层按"设备持有"逻辑：主机客户→配件转化→生态多设备（多设备持有者 CLV 3-5 倍）；增补设备型号/购买日期标签用于以旧换新圈选；复购分析按"主机-配件-换代"三条线 |
| promo-review | 增补维度：价保成本（大促后 30 天价保申请率）、以旧换新参与率、配件搭售率、新品首发达成 |
| ad-compliance-check | 强制行业附加：3C 认证标志与证书编号、性能参数须检测报告（续航标测试条件、防水标 IPX 等级与测试标准、像素标传感器型号）、"全球首发/首创"须权威认定、对比广告须同条件测试数据 |
| review-insight | 主题库预置：性能虚标（无条件 P0，涉虚假宣传）、品控（发热/异响/缝隙）、系统 BUG/固件、售后响应（维修时效/备件等待）、物流保价 |
| ecom-daily-report | 增补指标：价保申请金额、配件搭售率、新品首销进度（vs 首发目标）、延保渗透率 |
| competitor-review | 对比重点：参数-价格矩阵（同价位配置对比是 3C 主战场）、首发权益、以旧换新补贴力度、服务网络覆盖 |

## 第 4 步 行业红线自查

- **3C 认证**：强制目录内产品无 3C 证书不得销售宣传，证书编号须可查；
- **参数虚标**：续航/像素/防水/内存速度等与检测报告不符 → 虚假宣传 P0，且是差评引爆点；
- **测试条件标注**：续航"XX 小时"必须标测试条件（亮度/音量/网络），否则按夸大处理；
- **对比广告**：与竞品参数对比须同测试条件+可溯源数据，不得选择性对比；
- **"首发/首创/全球领先"**：须权威认定或可证事实（专利号/发布会记录），否则 P0；
- **以旧换新**：估价规则透明、旧机数据清除承诺、补贴条件明示；
- **价保规则**：价保范围/时限/例外须显著公示，大促前改价保规则是投诉重灾区。

## 第 5 步 延伸引导

- 有销售/会员数据 → crm-analytics（设备持有分层参数）；
- 配件耗材复购计划 → member-lifecycle-calendar（耗材周期版）；
- 新品上市库存与清尾 → inventory-alert（贬值型逻辑）；
- 参数宣称合规扫描 → ad-compliance-check（3C 附加规则）；
- 需要企业级能力（售后工单对接、以旧换新估价引擎）→ 联系凯淳 WISE 技术交付中心。
