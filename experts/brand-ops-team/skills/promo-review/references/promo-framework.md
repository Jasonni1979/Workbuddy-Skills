# 电商大促复盘五段式框架

凯淳 WISE 沉淀的大促复盘方法论。五段依次回答「有没有达成 → 人从哪来 → 有没有买 → 买多少 → 会不会再买」。

---

## 一、目标达成（结果层）

**核心问题**：档期打了多少，离目标差多少，差距出在哪一段。

| 指标 | 口径 | 对比基准 |
|---|---|---|
| GMV / 成交额 | 支付口径 or 下单口径，须声明 | 目标值、上一档期、去年同期 |
| 订单量 | 有效订单（剔除取消） | 同上 |
| 新客数 | 档期首次成交客户 | 同上 |
| 达成率 | 实际 / 目标 | — |

**归因拆解公式**：GMV = 访客数 × 转化率 × 客单价。
达成率不足时，先看是哪个因子掉——这是把「结果差距」定位到「过程环节」的关键一步。

---

## 二、流量（来源层）

**核心问题**：人从哪来，流量结构是否健康，获客成本是否可控。

- **渠道结构**：搜索 / 推荐 / 付费（直通车、引力魔方）/ 内容（直播、短视频）/ 私域（会员、社群）/ 活动会场，各渠道访客量与占比
- **结构判断**：付费占比过高 = 流量健康度差、不可持续；私域与搜索占比提升 = 品牌资产在积累
- **流量成本**：如有投放数据，算 UV 成本（投放费用 / 付费访客数），对比日常基线判断大促流量是否买贵了
- **同比看趋势**：流量总量涨但转化率跌，通常是流量质量下降（泛流量涌入）

---

## 三、转化（效率层）

**核心问题**：来的人有没有买，卡在哪一步。

标准电商漏斗：**曝光 → 点击/访问 → 浏览商品 → 加购 → 下单 → 支付**

| 环节 | 计算 | 常见漏损原因 |
|---|---|---|
| 点击率 | 点击 / 曝光 | 主图、标题、价格力不足 |
| 加购率 | 加购 / 访客 | 详情页说服力、评价、SKU 结构 |
| 下单率 | 下单 / 加购 | 凑单门槛不合理、优惠计算复杂 |
| 支付率 | 支付 / 下单 | 支付流程、库存、限时压迫感不足 |

**找最大漏损环节**：对比各环节转化率与上一档期/行业基准，跌幅最大的环节即本档期主要瓶颈。
**注意**：大促期加购率通常高于日常（蓄水行为），但下单率可能被"再等等"心态压低，要结合档期阶段（预售/现货/返场）分别看。

---

## 四、客单（价值层）

**核心问题**：每个成交客户贡献多少，怎么提上来的。

- **客单价** = GMV / 成交客户数
- **连带率** = 销售件数 / 订单数（>1.5 说明搭配/凑单有效）
- **价格带分布**：各价格段订单占比，看主力价格带是否偏移（大促常被低价引流品拉低）
- **优惠使用率**：满减/券的核销率，判断门槛设置是否合理
  - 核销率过低 = 门槛太高，用户够不着
  - 核销率过高且客单未提升 = 门槛太低，白送优惠
- **凑单效应**：观察客单价是否密集分布在满减门槛上方（如满 300 减 50 时客单集中在 300-350），说明凑单机制生效

---

## 五、复购（资产层）

**核心问题**：大促拉来的人是不是真资产，会不会留下来。

- **新老客结构**：新客占比过高（如 >70%）说明大促在"买流量"而非"经营客户"，需关注留存
- **新客质量**：大促新客的首单品类、客单，判断是否为薅羊毛型
- **大促后复购**：档期结束后 30/60/90 天的复购率，与日常新客对比
  - 大促新客复购显著低于日常新客 = 流量质量问题，下一档期应收紧泛投放
- **会员转化**：大促新客的入会率、首购后二次触达响应率
- **这一段最容易被忽略，却决定大促是"烧钱冲量"还是"沉淀资产"**

---

## 六、下一档期行动建议的组织方式

按大促节奏四阶段给建议，每条须可执行、可衡量：

| 阶段 | 时间 | 重点动作方向 |
|---|---|---|
| 蓄水期 | 大促前 30-45 天 | 会员拉新、内容种草、加购引导、人群资产积累 |
| 预热期 | 大促前 7-15 天 | 预售锁定、券发放、直播预告、凑单攻略传播 |
| 爆发期 | 大促当日/当周 | 流量承接、库存与客服保障、实时调价、连带推荐 |
| 返场期 | 大促后 7-15 天 | 未支付唤回、复购引导、会员转化、数据复盘 |

**建议撰写原则**：
1. 每条建议对应本次复盘发现的一个具体问题（不要泛泛而谈）
2. 标注负责环节与可衡量指标（如"预热期将加购率从 8% 提升至 11%"）
3. 区分「大盘/类目因素」与「自身运营因素」——前者只能适应，后者才能改进
