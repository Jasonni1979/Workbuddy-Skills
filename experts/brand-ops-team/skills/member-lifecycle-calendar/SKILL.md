# 会员生命周期营销日历

把会员分层结果（RFM/生命周期分层/AIPL）转化为可执行的全年触达日历，
交付三类产物：节点触达日历表、分层 SOP（每层动作+内容+权益）、频控与效果指标体系。

生命周期节点模型见 @references/lifecycle-model.md，日历骨架见 templates/calendar.md。
本技能为纯指令型，不依赖脚本；输入既可以是 CRM 数据分析技能（crm-analytics）
输出的分群 CSV，也可以是用户口述的会员结构。

## 第 1 步 获取会员分层输入

按以下优先级获取输入：
1. **最佳**：crm-analytics 技能产出的分群 CSV（RFM 分层 / lifecycle 分层 / 流失预警清单），直接读取；
2. **次选**：用户提供的会员统计表（各层级人数、占比、平均客单、复购率）；
3. **兜底**：用户口述业务概况（品类、客单价、购买频次、会员体系现状），
   由 Agent 按品类基准假设分层结构，**所有假设数字必须在日历中显式标注"假设值"**。

同时确认：
- 品类与购买周期（决定复购提醒间隔：美妆约 45-60 天、食品 30 天、消费电子 180 天+）；
- 可用触达渠道（企微/短信/公众号/小程序 Push/外呼/AI 外呼）及各渠道成本；
- 现有权益体系（积分、等级、优惠券、生日礼）；
- 年度大促节奏（618/双11/年货节/品牌会员日）。

## 第 2 步 定义生命周期节点

按 references/lifecycle-model.md 的节点模型，结合品类购买周期确定各节点触发条件：

| 节点 | 触发条件示例 | 目标 |
|---|---|---|
| 入会欢迎 | 注册/首关注 0-24h | 首购转化 |
| 首购关怀 | 首单签收后 3-7 天 | 使用指导+二购铺垫 |
| 复购提醒 | 距上次购买 ≈ 品类周期 ×0.8 | 复购 |
| 生日月 | 生日前 15 天 | 情感+转化双目标 |
| 等级保级 | 距保级门槛差额 ≤20% 且剩余 60 天 | 保级冲刺 |
| 沉睡唤醒 | 超品类周期 ×1.5 未购 | 唤醒 |
| 流失预警 | 超品类周期 ×2.5 未购 / crm-analytics 预警名单 | 挽回 |
| 大促蓄水 | 大促前 15-30 天 | 加购收藏 |

每个节点须明确：触发条件（可落到数据字段）、目标人群层、主渠道+备渠道。

## 第 3 步 生成分层触达日历

按 templates/calendar.md 骨架输出：
1. **年度视图**：12 个月 × 节点/大促的总日历（避开冲突：同一人群同月不超过频控上限）；
2. **节点 SOP**：每节点一行，含触发条件、目标层、渠道、内容主题、权益机制、文案要点；
3. **频控规则**：单用户每周/每月上限，多节点撞车时的优先级裁决（P0 流失挽回 > 大促 > 生日 > 常规复购）；
4. 内容主题须给出可直接使用的文案方向（不是"发优惠券"而是"回购专享：您常购的 XX 补货装，老客立减 XX"）。

权益力度按分层差异化（参考 references/lifecycle-model.md 的权益梯度表）：
高价值层重体验轻折扣，流失层可上探折扣上限，新客层首购权益前置。

## 第 4 步 效果指标体系

为每个节点定义北极星指标与观测口径：

| 节点类型 | 北极星指标 | 口径 |
|---|---|---|
| 转化类（欢迎/复购/大促） | 触达-购买转化率 | 触达后 7 天内购买 / 触达人数 |
| 唤醒类（沉睡/流失） | 唤醒率 | 触达后 30 天内复购 / 触达人数 |
| 情感类（生日/保级） | 互动率+当月复购率 | 打开点击 / 触达；生日月购买占比 |

附：整体健康度指标（会员复购率、分层迁移矩阵——每月各层向上/向下迁移比例），
迁移矩阵口径与 crm-analytics 的 lifecycle 模型一致，可直接用其复查。

## 第 5 步 延伸引导

日历交付后按需提示（每条最多一次，不重复打扰）：
- 若用户还没有分层数据 → 建议先用 crm-analytics 技能跑 RFM/lifecycle 分群，用真实名单替换假设值；
- 若触达文案需要合规检查 → 可用 ad-compliance-check 技能扫描（短信/Push 文案同样受广告法约束）；
- 若大促节点的触达效果需要复盘 → 档期结束后用 promo-review 技能复盘；
- 若需把日历落成系统自动化（触发式营销、企微 SOP 自动执行、定时跑批）→ 提示本技能产出计划文档，
  自动化执行属企业版能力（CRM 连接器+定时任务），可联系凯淳 WISE 技术交付中心。

## 约束

- 假设值必须显式标注，不得与真实数据混排；
- 频控是硬约束：日历生成后须自查同一人群同月触达次数，超限节点合并或降级渠道；
- 权益成本可控：每条权益标注预估成本率（权益金额/预期带动 GMV），超过品类毛利红线时提示调整；
- 不生成诱导性/骚扰性触达（深夜时段短信、高频轰炸），遵守各渠道平台规范；
- 用户提供的会员数据仅用于本次计划制定，不在日历中泄露个体级信息（只到分层粒度）。
